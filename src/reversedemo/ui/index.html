MoolAI HRIS Migration

Workday to BambooHR, through Striim

Worker records are read from the Workday Adaptive tenant, Striim replicates them between two PostgreSQL databases by log-based CDC, and each person is then created in BambooHR. The dots below are live health checks, not decoration.
